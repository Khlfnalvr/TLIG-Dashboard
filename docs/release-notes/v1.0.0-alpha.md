## v1.0.0-alpha — Custom Tunnel Domain, User Management, Credential Login

### New

- **Custom Cloudflare Tunnel domain.** The Server address stays the same after restart. DNS is created automatically after one browser login.
- **User Management** (Administrator). Add, edit, reset password, enable, disable, and delete users.
- **Credential login.** The Client logs in with username and password and receives a session token. Replaces the static access token.
- **Last username remembered** on the Server login form.

### Changes

- **Server camera** shows the full frame on the Dashboard and Live View.
- **Settings page** uses a 3-column layout.
- **Windows Firewall card and `FirewallHelper.cs` removed.** Cloudflare Tunnel handles public access.
- **Tunnel modes.** Quick tunnel (`*.trycloudflare.com`) and named tunnel (custom domain).
- **Separate Inno Setup scripts** for Server and Client.

### Compatibility

- **Prerelease.** Features can change.
- **System requirements.** Windows 10 build 17763 or later, x64, and an internet connection for Cloudflare Tunnel and AI Chat.

### Installation

- **Server.** Install on the PC connected to the camera and lab devices.
- **Client.** Install on other PCs to access the camera, HMI, and AI remotely.
