## v1.0.0-Hotel — Fix OPC DA Stuck at "Connecting..."

### Fixes

- **OPC DA no longer stays at "Connecting...".** Cause: COM ran on an MTA thread while the UI thread was blocked, which caused a deadlock. Solution: `Task.Yield()` keeps COM calls on the STA UI thread.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
