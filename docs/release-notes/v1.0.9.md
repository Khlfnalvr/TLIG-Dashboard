## v1.0.9 — LabVIEW Values on the Client Dashboard

### Fixes

- **LabVIEW Data card on the Client.** Flow Tube, PV, Flow Shell, and Temp. Shell out are shown on the Client Dashboard and Live View. Previously they were shown only on the lab PC.
- **Cause.** The VI connects to `127.0.0.1:6001`, which only the lab PC can receive.
- **Solution.** The Server provides read-only `GET /hmi/latest`. The Client polls it once per second (delay under 2 s).

### Changes

- **Access is filtered by the Server based on the login.** Lecturer, Assistant, and Admin: always visible. Student: visible only during their own turn.
- **Students without a turn** see the card with a message that values appear when their turn starts.
- **No stale values.** If the VI stops, the card shows "Tidak tersambung" and clears all values.
- **No other changes.** The lab PC dashboard, valve/PID path, queue logic, UI text, database schema, and LabVIEW VI are unchanged.

### Compatibility

- **Update both Server and Client.** Client v1.0.9 with Server v1.0.8 shows the Server as unreachable on the card. Client v1.0.8 with Server v1.0.9 works; the card stays hidden.
- **Rollback.** Reinstall v1.0.8. No data is lost because the database schema is unchanged.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
