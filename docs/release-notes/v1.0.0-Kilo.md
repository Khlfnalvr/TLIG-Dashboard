## v1.0.0-Kilo — Theme Update, Gemini Provider, LabVIEW TCP Connection

### New

- **Google Gemini provider** (gemini-3.1-pro-preview, gemini-3.5-flash, gemini-3.1-flash-lite) through the OpenAI-compatible endpoint. Configured in the AI provider dialog.
- **AI model catalog updated.** DeepSeek `deepseek-v4-flash` and `deepseek-v4-pro` (old IDs deprecated on 24 July 2026), OpenAI GPT-5.5 and GPT-5.4 (including mini and nano), Anthropic Claude Opus 4.8, Sonnet 5, Sonnet 4.6, and Haiku 4.5.
- **PlcTcpService.** Replaces the OPC UA/DA service with a direct TCP connection to the LabVIEW HMI using `name=value` lines.

### Fixes

- **HMI labels update correctly** after changing the process system and returning to the Dashboard.
- **Process selector icons.** Flow uses a droplet icon (previously an empty box). Level uses a level-bar icon (previously the same as Temperature).

### Changes

- **Process selector theme.** Uses WinUI 3 theme resources and follows the light or dark theme and system accent color.
- **Learning Analytic.** The task progress summary is shown only to students on the Client. On the Server and for staff, it starts at Challenge Learning.
- **Student roster** for grading is taken from registered accounts.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
