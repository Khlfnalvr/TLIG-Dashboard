## v1.0.0-Golf — OPC DA Connection Feedback

### Fixes

- **"Connecting..." is shown during connection.** `ConnectAsync` runs in `Task.Run`.
- **ServerState probe is optional.** It is skipped if the server does not support it.
- **Error messages are shown** in the status text on the Settings page and flyout.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
