## v1.0.5 — Valve Opening and STOP/RESET/E-STOP Sent to LabVIEW

### Fixes

- **Valve opening and STOP/RESET/E-STOP reach LabVIEW.** They are moved from the port 6001 CSV line to the port 6000 binary packet, the same path as Kp, Ki, Kd, and Setpoint.

### Changes

- **STOP, RESET, and E-STOP no longer stop the Python process.** Commands are latched and the connection stays open. The process stops when the dashboard is closed.
- **Default PythonScriptPath is empty.** `PIDtest.py` next to the executable is used. The previous default (drive D) failed on some PCs.
- **Other.** New cascade transfer function, simulator audit P0–P3, AI gain validation, XAML cascade block diagram, AI token context ring, and saved chat sessions.

### Compatibility

- **Update the LabVIEW VI before installing.** The port 6000 packet is now 6 doubles (48 bytes): SP, KC, KI, KD, PUMP, CMD.
  1. TCP Read: change bytes to read from 32 to 48.
  2. Unflatten From String type cluster: change 4 DBL to 6 DBL.
  3. Unbundle: change 4 elements to 6.
  4. Wire element 5 to the valve opening (MV) control.
  5. Wire element 6 through To Long Integer to a Case structure (0/1/2/3 + Default).
- **Command codes.** RUN = 1, STOP = 0, RESET = 2, E-STOP = 3.
- **Warning.** A VI that still reads 32 bytes shows no error but displays incorrect values.
- **Server only.** The Client sends commands through the Server over HTTP and is not affected.
- **Rollback.** Reinstall v1.0.4.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
