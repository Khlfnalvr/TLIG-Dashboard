## v1.0.8 — Single-User Plant Queue and Experiment History

### New

- **Queue status strip** on the Control card: current user, elapsed time, your queue position, and your remaining time.
- **Queue priority.** Admin → Lecturer/Assistant → Student; first come, first served within a level. A higher role can take over; the displaced user returns to the front of their level.
- **Notifications** at the top of the window: turn started, 5 and 1 minutes remaining, and turn ended by the system.
- **RUN rejection message** shows the current user, role, elapsed time, and your queue position.
- **Cabut paksa (force release)** for Lecturer, Assistant, and Admin. It releases the turn even if STOP fails and warns that the rig may still be running.
- **Experiment history for students.** Challenge Learning page → **Riwayat Percobaan Saya**, with CSV export. Shows only the student's own runs; filtering is done by the Server.
- **Presence in User Management.** The Status column shows *Aktif*, *Tidak aktif*, or *Dalam antrean*, with a sub-status. *Aktif* means the application is open (heartbeat under 1 minute).

### Changes

- **One user controls the plant at a time.**
- **RUN (JALANKAN).** If the plant is in use, RUN adds you to the queue and sends no command to LabVIEW.
- **STOP (BERHENTI) releases the turn.** RESET and E-STOP do not release the turn.
- **Student turns are limited to 30 minutes.** At timeout, the Server sends STOP, then passes the turn to the next user. Lecturer, Assistant, and Admin have no limit.
- **Closing the application or logging out** sends STOP, then releases the turn.
- **Failed STOP keeps the turn.** If STOP cannot be delivered, the turn is not released automatically. Staff can use **Cabut paksa**.
- **Interrupted runs are saved** with their curves and the status *Terputus*.
- **RUN always runs the plant.** No stored results are returned instead.

### Compatibility

- **No LabVIEW VI changes.** The 48-byte packet and CSV format are unchanged.
- **Update the Server and all Clients.** Older Clients do not recognize the "in use" response, and RUN fails without a message.
- **Rollback.** Reinstall v1.0.6. Queue and history data are stored separately; no data is removed.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
