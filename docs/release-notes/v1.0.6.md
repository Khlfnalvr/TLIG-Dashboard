## v1.0.6 — Client Valve Opening Reaches LabVIEW

### Fixes

- **Valve opening from the Client reaches LabVIEW.** Previously only the Server value worked. Setpoint, Kp, Ki, and Kd already worked.
- **Cause.** The VI reads the valve opening from port 6001, which only the lab PC (`127.0.0.1`) can reach.
- **Solution.** On RUN or SYNC from a Client, the Server forwards the command on its own port 6001 connection as CSV `Kp,Ki,Kd,Setpoint,Pump,Cmd`. STOP, RESET, and E-STOP use the same path.
- **RUN button no longer stays disabled.** Port 6001 writes no longer run on the UI thread.
- **AI Advisor timeout.** Requests are limited to 120 s.

### Compatibility

- **Update the Server only.** No Client or LabVIEW VI change is required. Packet and CSV formats are unchanged.
- **Rollback.** Reinstall v1.0.5.

### Installation

- **New installation.** Install the Server setup on the lab PC.
- **Existing installation.** Open the application and select the update notification to install.
