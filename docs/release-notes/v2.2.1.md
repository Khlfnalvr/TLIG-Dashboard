## v2.2.1 — Plant vs. Simulation Charts, Client Routed Through Server

### New

- **Two response charts.** Outer loop (temperature): RK4 simulation, single-loop baseline, setpoint, and measured **Temp. Shell out**. Inner loop (flow): simulated flow, flow setpoint, and measured **Flow Tube**.
- **Chart visibility.** A Server run is shown only on the Server. A Client run is shown on the Server and on that Client. PLC curves remain after STOP until the next RUN.
- **Inner-loop Kp and Ki on the Dashboard.** Inner-loop gains are used only by the simulation. The LabVIEW packet is unchanged (SP, KC, KI, KD, PUMP, CMD).
- **System Status panel.** PLC is *Online* when Connect is active or the VI is connected on port 6001. Sensor is *Active* when LabVIEW data is less than 3 s old. The Client shows the Server status.

### Changes

- **Includes V2.2.** V2.2 (v1.2.0 assets, built from a separate branch) is merged into master. The version is 2.2.1 so that V2.2 installations detect the update.
- **Temperature only.** The Flow/Level/Temperature selector is removed. Challenges always target temperature. Existing challenge data is migrated and submissions are kept.
- **No direct Client connection to LabVIEW or the PLC.** The PLC tab is hidden and the Client does not open port 6001.
- **Server-side data for the Client.** Cascade simulation: `POST /sim/cascade`. PLC and sensor status: `GET /system/status`. PLC PID metrics for Challenges: `/hmi/latest`.
- **Cross-device chat memory removed.** The feature is kept on branch `fitur/chat-memory-sync`. Chat history is stored per laptop, as in v1.0.9.

### Compatibility

- **Update the Server before the Client.** Use v2.2.1 for both.
- **Client v2.2.1 with Server V2.2/v1.2.0.** Works, but PLC curves are empty.
- **Older Client with Server v2.2.1.** Works as before.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
