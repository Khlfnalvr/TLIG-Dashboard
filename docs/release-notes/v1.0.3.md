## v1.0.3 — LabVIEW Port 6001 and Client PID Control

### New

- **LabVIEW data port field (6001)** on the PLC Connection card.
- **Client PID control.** The Client can run the PID in LabVIEW through the Server.
- **LabVIEW chart sync.** Seven LabVIEW chart variables are shown on the dashboard, with reply diagnostics and a more flexible parser.

### Fixes

- **Telemetry port.** The LabVIEW telemetry listener is moved from TCP 5005 to TCP 6001 (`PIDtest.py` and dashboard).
- **Theme.** Light and dark themes are consistent on code-built pages.
- **Control labels.** "Bukaan Valve (%)" and "Bukaan Pump (%)".

### Changes

- **ML PID subsystem removed.** SDCA classifier, FastTree regressor, and training CSV files.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
