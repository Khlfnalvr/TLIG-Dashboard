## v2.2.7 — Cascade Manual/Auto Mode, PID Gain Conversion, Flow 0–4.65 L/min

### New

- **Manual/Auto mode in Cascade Control.** Auto: the PID controls the valve from 0–100%. Manual: the valve is held at the **Bukaan Valve** value without PID, and the chart shows the open-loop response.
- **Manual-mode metrics.** Rise time, overshoot, and settling time are measured against the final temperature. Steady-state error and IAE/ISE/ITAE are measured against the setpoint.
- **Mode selection.** The Manual/Auto selection on the Dashboard controls the simulation. The Cascade page follows it.
- **Best-available tuning.** If no "Ideal" candidate exists, the Advisor recommends the fastest stable tuning within limits that improves on the current gains.

### Fixes

- **PID gains are converted for LabVIEW.** The NI PID uses Kc, Ti (min), and Td (min). Conversion: Kc = Kp, Ti = Kp/Ki/60, Td = Kd/Kp/60. Previously the integral action was thousands of times too strong. Applies to the Dashboard, Parameter page, and Client runs.
- **Flow range matches the rig.** 0–4.65 L/min (previously 1–7 L/min). Simulated flow cannot be negative.
- **Chart reaches the setpoint at all reachable temperatures.** Flow disturbance is scaled to the remaining valve capacity. The single-loop comparison uses equivalent gains (previously about 21× too weak).
- **Steady-state error is shown in percent.** Recommended gains are not rounded.
- **AI Advisor panel closes after "Ya (Terapkan)".** Applied gains are sent to LabVIEW immediately.
- **Transfer function card.** Gp2 = 0.0465 (previously 0.06).

### Compatibility

- **Update the Server before the Client.** The Client cascade simulation runs on the Server.
- **Mixed versions.** Client v2.2.6 works with Server v2.2.7. Client v2.2.7 with an older Server has no Manual mode.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
