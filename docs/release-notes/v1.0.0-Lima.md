## v1.0.0-Lima — Cascade PID, PID Advisor, LabVIEW TCP Bridge

### New

- **Cascade PID control** (temperature and flow) with a FOPDT plant from lab data, RK4 simulator, and IAE/ISE/ITAE indices.
- **History-aware PID Advisor** with calculated diagnosis and targeted-search recommendations.
- **LabVIEW TCP bridge** (`PIDtest.py`). Live data between the dashboard and LabVIEW HMI, two-way control, and configurable host and port.
- **AI chat uses verified gains** from cascade and PID data.
- **User guide.** `PANDUAN_PENGGUNAAN.md` is added to the repository.

### Installation

- **Server.** Install on the lab PC connected to the PLC/HMI.
- **Client.** Install on lecturer, assistant, and student devices.
- **Existing installation.** The in-app update detects this release automatically.
