## v1.0.4 — Response Charts, Simulator Fixes, AI Gain Validation

### New

- **Temperature and flow response charts** on the Dashboard.
- **Native XAML cascade block diagram.**
- **AI token context ring and saved chat sessions**, integrated with the simulation.

### Fixes

- **PID simulator.** Saturation, anti-windup, and setpoint-based settling time.
- **AI gain validation.** Suggested gains are validated (GainValidator). Verification corrections are saved to history.

### Changes

- **AI Advisor.** Standard advisor context, API retry, parallel recommender, and AdvisorCore.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
