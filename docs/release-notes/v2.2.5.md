## v2.2.5 — Native Charts, Fixed Server Address, Adaptive Camera

### New

- **Native charts.** Outer-loop, inner-loop, and PID step-response charts no longer use WebView2 or Chart.js.
  - No `msedgewebview2.exe` process is started per chart.
  - No internet connection is required to draw charts.
  - The "We couldn't create the data directory" error and empty charts in Program Files installations are fixed.
- **Chart controls.** Ctrl + scroll: zoom. Drag: pan. Double-click or **Reset**: reset view. Hover: show value. Click legend: show or hide a series.
- **Fixed Server address.** The Client always connects to `icolaboratory.com` and no longer asks for a Server address. Laptops with a different saved address are switched automatically and must log in once.
- **Adaptive camera card.** On the Client Dashboard and Live View, the camera card is hidden while the Server is not broadcasting. The HMI uses the full width.
- **Theme-aware block diagram.** The cascade block diagram on the Dashboard and Parameter page follows the light or dark theme.

### Compatibility

- **Server tunnel.** The Server must use a Cloudflare Named Tunnel on `icolaboratory.com`. Quick Tunnel (`*.trycloudflare.com`) and LAN addresses (`192.168.x.x:8088`) no longer work for Clients.
- **Update the Server before the Client.** No protocol or database changes since v2.2.1. Any Client and Server from v2.2.1 onward work together.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
