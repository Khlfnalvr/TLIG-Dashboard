## v1.0.0-beta — Client Sign-Up, Learning Analytics Page, Auto-Update Fixes

### New

- **Client sign-up.** Users can register from the login page ("Belum punya akun? Daftar"). Only `@its.ac.id` addresses, including subdomains, are accepted. New accounts receive the Viewer role. Endpoint: `POST /auth/signup`.
- **Learning Analytics page.** Performance ring, completion rate, KPI cards, course progress table, and pending tasks and quizzes.

### Fixes

- **Auto-update works.** Four defects are fixed:
  1. GitHub API URL pointed to the wrong repository.
  2. `FindPayloadPath` searched for an executable that does not exist in the Server/Client builds.
  3. The apply script started an executable that does not exist.
  4. Menu and bug-report links pointed to the old repository.

### Changes

- **`release.ps1`.** One command publishes Server and Client, creates update ZIPs, and compiles the installers.
- **Git exclusions.** `cloudflared.exe` and `publish/` are excluded.

### Compatibility

- **Prerelease.** Feature-complete; for internal evaluation.
- **System requirements.** Windows 10 version 1809 (build 17763) or later, x64.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
