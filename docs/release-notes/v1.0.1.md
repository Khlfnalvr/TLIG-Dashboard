## v1.0.1 — Unused ML PID Subsystem Removed

### Changes

- **No user-visible changes.**
- **ML PID subsystem removed.** SDCA diagnosis classifier, four FastTree metric regressors, two training CSV files, and the Microsoft.ML dependency.
- **Diagnosis unchanged.** Diagnosis remains rule-based (PidDiagnosisCalculator). LLM Advisor, AI Chat, and Cascade diagnosis are unchanged.
- **Result.** Smaller package and faster startup.
