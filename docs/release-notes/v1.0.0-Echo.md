## v1.0.0-Echo — OPC DA (Classic) Support

### New

- **OPC DA protocol** in addition to OPC UA. Select it in the connection flyout or Broadcast Settings page.
- **ProgID connection** (for example, `National Instruments.NIOPCServers.V5`) through COM. No additional installation is required.
- **Saved settings.** Protocol and ProgID are kept after restart.

### Installation

- **Update ZIP only.** Existing installations do not need an installer.
