## v1.0.0-India — Learning Tasks and Lecturer/Assistant/Student Roles

### New

- **New roles.** Dosen (Lecturer), Asisten (Assistant), and Mahasiswa (Student) replace Admin, Operator, and Viewer. Existing accounts are migrated automatically.
- **Role access.** Lecturers and Assistants manage learning analytics. Students view and complete assigned tasks. Student accounts cannot log in to the Server application.
- **Task list** on the Learning Analytic page with an overall progress gauge.
- **Task editing (staff).** Title, objective, and an optional target (for example, *Rise time ≤ 2 ± 0.2 s*).
- **Task detail page.** Students mark tasks complete or undo. Staff edit or delete tasks.
- **Server storage.** Tasks and completion status are stored on the Server (`tasks.json`) and accessed through `/tasks`. Write access is limited to staff.
- **Dashboard panel.** The Learning Analytic panel shows the same content as the full page.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
