## v1.0.0-Juliet — Multi-Provider AI and AI Chat Fix

### New

- **OpenAI and Anthropic providers** in addition to DeepSeek, with protocol translation including SSE streaming.
- **Shared model picker** on the AI page and in the Dashboard chat.
- **Server-managed providers.** The Server enables providers and models and stores the API keys. Keys are never sent to Clients.
- **Remote provider configuration.** Lecturers and Assistants can configure providers from the Client.

### Fixes

- **"AI chat error" on new installations.** Cause: reflection-based JSON serialization is disabled in the trimmed Release build. The request body is now built with `JsonObject`/`JsonArray`.

### Changes

- **Grading feature scaffolding merged.** Duplicate files are removed.

### Installation

- **New installation.** Install the Server setup on the lab PC and the Client setup on each laptop.
- **Existing installation.** Open the application and select the update notification to install.
